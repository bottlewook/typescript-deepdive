### 🔥 정리하기

#### 1. 타입 추론이란?
타입 추론이란 타입스크립트가 코드를 해석하여 적절한 타입을 정의하는 동작을 의미
```javascript
var a = 10; // number 타입
```

위 코드는 변수 초기화 시점에 할당된 값에 따라 자동으로 타입이 추론된다

#### 2. 변수의 타입 추론 과정

```javascript
var a; // any
a = 10 // number 타입 추론 안됨

// 이후에 어떤 코드가 올지 타입스크립트는 알 수 없다.
```

#### 3. 함수의 타입 추론: 반환 타입
```javascript
function sum(a: number, b: number) {
  return a + b
}

function sum(a: number, b: number) {
  return a === b
}

// 반환 타입을 명시해주지 않아도 자동으로 number 타입으로 추론된다
// 2번째 코드는 자동으로 반환 타입이 boolean 타입으로 추론된다.
```

#### 4. 함수의 타입 추론: 파라미터 타입
```javascript
function gatA(a = 10) {
  return a
}

// 기본값을 할당하면 자동으로 할당된 타입을 추론한다.
// 기본값이 있기에 ? 옵셔널 파라미터가 적용된다
```

#### 5. 인터페이스와 제네릭의 추론 방식
```javascript
interface Dropdown<T> {
  title: string;
  value: T;
}

let shoppingItem: Dropdown<number> = {
  title: '길벗 책', // string 타입 추론
  value: // number 타입 추론
}
```
