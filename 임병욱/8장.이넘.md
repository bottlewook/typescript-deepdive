### 🔥 정리하기

#### 1.이넘이란
이넘은 특정 값의 집합을 의미하는 데이터 타입

#### 2. 숫자형 이넘
```javascript
enum Direction {
  Up, // 0
  Down, // 1
  Left, // 2
  Right // 3
}
```
컴파일 과정에서 enum 타입은 사라지지 않고 아래와 같은 형식으로 변환된다.
```javascript
'use strict'
var Direction;
(function (Direction) {
  Direction[Direction['Up'] = 0] = 'Up';
  Direction[Direction['Down'] = 1] = 'Down';
  Direction[Direction['Left'] = 2] = 'Left';
  Direction[Direction['Right'] = 3] = 'Right';
})(Direction || (Direction = {}));

console.log(Direction)

// 이넘의 속성과 값이 거꾸로 연결되어 할당되어 것은 리버스 매핑이라한다.
{
  Up: 0,
  Down: 1,
  Left: 2,
  Right: 3,
  0: 'Up',
  1: 'Down',
  2: 'Left',
  3: 'Right'
}
```

이넘 속성의 초기값을 변경하려면
```javascript
enum Direction {
  Up = 10,
  Down, // 11
  Left, // 12
  Right // 13
}
```

#### 3. 문자형 이넘
이넘의 속성 값에 문자열을 연결한 이넘을 의미
숫자형 이넘과 달리 모든 속성 값을 모두 문자열로 지정해야함
```javascript
enum Direction {
  UP = 'UP',
  DOWN = 'DOWN',
  LEFT = 'LEFT',
  RIGHT = 'RIGHT'
}
```

#### 4. 알아 두면 좋은 이넘의 특징
1. 혼합 이넘
```javascript
enum Answer {
  Yest = 'Yes',
  No = 1
}
```
2. 다양한 이넘 속성 값 정의 방식
```javascript
enum Authorization {
  User, // 0
  Admin, // 1
  SuperAdmin = User + Admin, // 1
  God = 'abc'.length // 3
}
```

3. const 이넘
이넘을 선언할 때 앞에 const를 붙인 이넘을 의미한다.
```javascript
const enum logLevel {
  Debug = 'Debug',
  Info = 'Info',
  Error = 'Error'
}

컴파일 결과
'use strict'
```
const enum은 기본 enum과 컴파일 결과가 다르게 나타난다.
