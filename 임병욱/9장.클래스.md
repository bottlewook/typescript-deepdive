### 🔥 정리하기

#### 1. 클래스란
여러 가지 유사한 **객체**를 쉽게 생성하는 자바스크립트 최신 문법
```javascript
class Person {
  constructor(name, skill) {
    this.name = name;
    this.skill = skill;
  }
}
```

#### 2. 클래스 기본 문법
```javascript
// 생성자 함수 이용
function Person(name, skill) {
  this.name = name
  this.skill = skill
}

Person.prototype.sayHi = function() {
  console.log('hi')
}

// 클래스 문법 이용
class Person {
  // 생성자 메서드
  constructor(name, skill) {
    this.name = name;
    this.skill = skill
  }

  // 클래스 메서드
  sayHi() {
    console.log('hi')
  }
}
```

#### 3. 클래스의 상속
클래스의 상속이란 부모 클래스의 속성과 메서드 등을 자식 클래스에서도 사용할 수 있게 물려준다는 의미

```javascript
class Person {
  // 생성자 메서드
  constructor(name, skill) {
    this.name = name;
    this.skill = skill
  }

  // 클래스 메서드
  sayHi() {
    console.log('hi')
  }
}

class Developer extends Person {
  constructor(name, skill) {
    super(name, skill)
  }

  coding() {
    console.log('fun doing' + this.skill + this.name)
  }
}
```

#### 4. 타입스크립트의 클래스
```javascript
class Chatgpt {
  constructor(name: string) {
    this.name = name // 타입 에러
  }

  sum(a: number, b: number): number {
    return a + b
  }
}

아래의 형식으로 타입을 정의해야 타입 에러가 발생하지 않는다.
class Chatgpt {
  name: string

  constructor(name: string) {
    this.name = name
  }

  sum(a: number, b: number): number {
    return a + b
  }
}
```

#### 5. 클래스 접근 제어자
1. 클래스 접근 제어자의 필요성
```javascript
class WaterPurifier {
  waterAmount: number;

  constructor(waterAmount: number) {
    this.waterAmount = waterAmount
  }

  wash() {
    if (this.waterAmount > 0) {
      console.log('정수기 동작 성공')
    }
  }
}

var purifier = new WaterPurifier(30);
purifier.wash();
purifier.waterAmount = 0;
purifier.wash(); // 의도치 않은 코드 변경
```

2. 클래스 접근 제어자: Public, private, protected
- public
1. public 접근 제어자는 클래스 안에 선언된 속성과 메서드를 **어디서든** 접근 가능할 수 있게 해준다.
클래스 속성과 메서드에 별도로 속성 접근 제어자를 선언하지 않으면 기본겂은 public이 된다.

- private
private 접근 제어자는 클래스 코드 외부에서 클래스의 속성과 메서드에 접근할 수 없다.

```javascript
class Person {
  private name: string
  private skill: string

  constructor(name: string, skill: string) {
    this.name = name;
    this.skill = skill
  }

  private sayHi() {
    console.log('hi')
  }
}

var hulk = new Person('헐크', '소리치기');
console.log(hulk.name); // name 속성은 private이며 클래스 내에서만 액세스할 수 있습니다.
```

- protected
protected로 선언된 속성이나 메서드는 클래스 코드 외부에서 사용할 수 없다.
private 접근 제어자는 상속된 자식에서도 사용할 수 없지만 protected 접근 제어자는 상속된 자식에서 사용 가능하다.

```javascript
class Person {
  private name: string
  private skill: string

  constructor(name: string, skill: string) {
    this.name = name;
    this.skill = skill
  }

  protected sayHi(): void {
    console.log('hi')
  }
}

class Developer extends Person {
  constructor(name: string, skill: string) {
    super(name, skill);
    this.sayHi() // 에러 발생하지 않음
  }

  coding(): void {
    console.log('fun doing ' + this.skill + ' by ' + this.name) // 에러 발생
  }
}
```

#### 클래스 접근 제어자를 사용할 떄 주의해야 할 점
컴파일 과정이 아닌 런타임 과정에서 private 접근 제어자를 사용하고 싶다면 ES2020부터 도입된 #을 사용할 것
```javascript
class WaterPurifier {
  #waterAmount: number;

  constructor(amount: number) {
    this.#waterAmount = amount
  }

  public wash() {
    if (this.#waterAmount > 0) {
      console.log('정수기 동작 성공')
    }
  }
}

var purifier = new WaterPurifier(30);
purifier.wash(); // 정수기 동작 성공
purifier.#waterAmount = 0;
purifier.wash(); // 정수기 동작 성공
```
